# 013 · 移动端设计系统（安卓 4.1）

## 0. 起因

2026-09-06 真机（nubia，暗色）六张截图：录音台、我的、问、会议详情、记录、今天。
结论一句话：**不是某一处丑，是没有系统**。具体四个根子，每个都能在截图里指出来：

| 根子 | 截图里的样子 | 4.1 的处方 |
| --- | --- | --- |
| 层级只靠描边 | 黑底上满屏 1px 灰线空心框（我的、记录、录音台） | 暗色下卡片**靠底色抬一级、不描边**；浅色保留白底发丝边 |
| 按钮没有等级 | 38 个 TextButton；「兑现了」和「去那场会」长得一样，「删掉这条」满屏红 | 四档按钮：实心 / 填充 / 链接 / 安静。判据是**点了会发生什么** |
| 状态靠散文 | 「过期 3 天」是一行红字；「录下来 → 送到 → 转写完 → 分析完」四个词三灰一亮 | **药丸**：一个词 + 语义色；分析完的什么都不带 |
| 设置页是卡片墙 | 「我的」五张一样的框，账号 / 版本 / 反馈 / 网页 / 条款各一张 | **分组列表行**：DsGroup + DsRow + 缩进分隔线 |

「reaper 收尾：…」内部任务名、`note20260829-140354` 文件名当标题。这三处在 4.1 里一并修了（Markdown 表格按行摊开、锚去掉、`SessionTitles` / `Problems`）。

## 1. 原则

1. **带过去的是品牌，交还给平台的是形制。** 品牌 = 色、字阶意图、语气；平台 = 返回箭头、底栏、触感、命中区 48dp。
2. **蓝只花在两处**：实心的主动作（录音圆、悬浮话筒、下载新版）和「可点的文字」。tab 下划线、底栏选中、进度条都不是蓝——一屏三种东西都是蓝的时候，蓝就不再表示任何事。
3. **状态用词说，颜色只是加强。** 阳光下和色觉障碍面前颜色不可靠，所以「过期 3 天」「没成功」「猜想」都是字。
4. **不是所有东西都是卡。** 卡给「一个可操作的对象」（一条承诺、一场会）；设置是列表行；提示是嵌块；说明是一句灰字。
5. **同型必同宽。** 所有页左右留白同一个值（`DS.Pad.screen`），列表底部同一个页级空白。

## 2. Token（读代码）

| 类 | 在哪 | 判据 |
| --- | --- | --- |
| 色 | `Theme.kt` LightColors / DarkColors | 浅色：底 ink-50、卡白、主色品牌蓝。暗色**另取一套**：底 → 卡 → 嵌块 → 控件四级，每级差 ≥ 12/255，色相偏蓝；实心蓝与文字蓝是两档（白字在实心上 ≥ 4:1，文字蓝在底上 ≥ 7:1） |
| 语义色 | `Tone` + `Tone.colors()` | 好 / 警告 / 坏 / 信息 / 中性 / 品牌，各一对（底 + 字），明暗各一套。**屏幕里不直接用 StateColor** |
| 字阶 | `ShennaoTypography` | 四个落点：页题 headlineSmall（每屏一个）/ 读文 bodyLarge（比界面字大）/ 界面 bodyMedium / 元信息 bodySmall（等宽数字）。字重只用粗、中、常规。**一屏之内 bodySmall 不多于 bodyLarge** |
| 节奏 | `DS.Rhythm` | 七档，从 page 到 hair；数值读代码。判据：紧的更紧、松的更松，一屏里必须同时有两种。屏幕代码不写裸 dp |
| 圆角 | `DS.Radius` | tiny 4 / control 12 / card 16 / sheet 20 / pill |
| 尺寸 | `DS.Size` | hit 48 / icon 20 / iconLarge 32 / recordButton 88 |

## 3. 组件（`DS.kt`）

| 组件 | 用在 | 不要用在 |
| --- | --- | --- |
| `DsCard(tone)` | 一条承诺、一场会、一条判断。PLAIN / INSET（卡里的嵌块、念一句）/ ACCENT（正在录、刚录完）/ RISK / WARN | 设置项、一句说明 |
| `DsGroup` + `DsRow` + `RowDivider` | 我的、问的例句、灵魂卡状态条 | 需要多行正文的东西 |
| `Pill(text, tone)` | 过期 N 天、上传中 / 转写中 / 分析中 / 没成功、有原话 / 推断 / 猜想、决定 / 信号 / 矛盾、已记 | 可点的东西（药丸不可点） |
| `NoticeBox(text, tone)` | 录音被系统停过、卡住的原因、没有麦克风权限 | 正常内容 |
| `PrimaryButton` | 一屏最多一个：开始录、下载新版、还是分析这条、再试一次 | 卡片上的动作 |
| `TonalButton` | 卡片上的记账动作：兑现了 / 取消了 / 应验了 / 对 / 不对 / 查看 / 加上 | 跳转 |
| `LinkButton` | 去别处看：去那场会、回到原话、看它凭什么、从灵魂卡导入、检查更新、复制 / 换一句 | 记账 |
| `QuietButton` | 低频不抢眼：删掉这条、别再看、退出登录、知道了。**红留给确认框** | 主动作 |
| `DsChip` | 场合、来源分段 | 状态（那是药丸） |
| `DsTabs` | 今天的频道、会议的判断 / 承诺 / 原话。字与下划线是 ink | — |
| `TopBar` | 详情页：返回箭头 + 右侧图标动作。**没有「返回」两个字** | 列表页 |
| `SectionLabel` / `SectionHead` | 列表分区（还在手机上）/ 详情分区（读出来的判断 + 一句说明） | — |

## 4. 各屏的改法（对着 4.0.1 截图）

- **今天**：页头只说最急的一件（去掉重复的计数行）；tab 变 ink；「过期 N 天」变药丸；「兑现了 / 取消了」变填充按钮；FAB 变圆。
- **记录**：灵魂卡状态条变列表行；来源分段变填充 chip；四步链变一个药丸；文件名标题变「录音 · 时间」；「reaper 收尾」去掉；「删掉这条」变安静按钮靠右；卡住原因变 RISK 嵌块。
- **会议**：顶栏箭头 + 分享图标；tab 变 ink；方法变品牌药丸；判断卡头部 = 主语 + 类型药丸 + 认知药丸；对 / 不对变填充；回到原话靠右；Markdown 表格按行摊开、`---` 变分割线、锚去掉；网页版按钮变填充满宽。
- **问**：输入框填充底不描边、发送图标有字才亮；空态靠上，三个例句是**能点的行**，点了直接问。
- **我的**：三组列表行（设备 / 账号 / 更多），后台录音一行带「未允许 / 已允许」药丸，版本一行右侧「检查更新」，有新版时才出实心按钮；退出登录是安静按钮。
- **录音台**：顶栏箭头 + 「从灵魂卡导入」链接；「准备好了」用页题字阶（不再是等宽细体）；场合变填充 chip；圆按钮 88dp 品牌蓝 + 话筒图标，「开始」写在圆下面；念一句变嵌块；底部说明变一句灰字不装框。

## 4.5 第二轮：字阶与疏密（4.1.1）

4.1.0 发出去后的反馈是「廉价」。看截图，病在两处：

- **档差太小。** 24 / 16 / 15 / 13——页题只比正文大一半，读文和界面字一样大，眼睛没有落点。
  重定四个落点：页题 28 粗、**读文 17/27**（原话、判断、摘要，比界面字大）、界面 14、元信息 12 等宽数字。
  字重只用粗 / 中 / 常规三档：很多国产 ROM 的中文字体没有 600，写了会退成 700。
- **到处都是 12。** 等距叠着的东西读起来像表格。疏密要同时存在：紧的更紧（标题和它的副行 4）、
  松的更松（分区之前 32）。卡片分三区：头（谁、什么时候，紧贴成一组）、身（读文）、底（一条发丝线 + 动作行）。
  记录页把「办完的」从卡片降成带发丝线的行，只有「还在路上的」才是卡——一屏里有卡有行，才分得出该管的和看看就行的。

## 5. 没做、以及为什么

- **没引图标库**（material-icons-extended 会让包从 10 MB 涨到 14 MB）。用到的箭头 / 分享 / 发送 / 右箭头都在 core 里；话筒和问气泡是手画的。
- **没做阴影**。层级靠底色阶梯，阴影是 Material 的语言不是深脑的。
- **没换字体**。中文跟系统字体是平台惯例；换字体多 10 MB 且在国产 ROM 上回退不可控。
- **没做动效**。这一版先把静态的层级、等级、状态理顺；动效是下一版的事，且判据只有一条：动的东西必须在说一件事。

## 6. 下一步（要真机看了才定）

字号整体是偏大还是偏小、卡片圆角 16 要不要收到 12、「今天」四个频道名要不要更短、暗色的卡片底够不够亮——这四条是口味，模拟器上判断不了。装 4.1.0 用两天，哪里别扭截图来。

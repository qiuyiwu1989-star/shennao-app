# 014 · 文案规范（安卓）

> 状态：**已落地**（4.3.1 / 54，2026-09-11）。
> 门禁：`CopyGuardTest` 扫给用户看的字符串，内部词和「——」出现就红；对话框按钮「算了 / 好 / 确定」也红。
> 这份文档只写**为什么**和**判据**；词表以测试里的为准，改词先改测试。

## 0. 声音

深脑说话像一个**在场的、靠谱的同事**：短句、口语、有判断、不推卸。
不是客服（「亲，请您稍后再试哦」），不是系统（「操作失败，错误码 500」），不是文案（「让每一次沟通都被看见」）。

三条判据：

1. **说的是发生了什么，不是我们做了什么。** 「录音已停止，已录到的都在」，不是「系统已终止录音进程」。
2. **每句话都给下一步。** 出错必带怎么办；空态必带能做什么；确认框必说做完会怎样。
3. **不替用户下结论。** 「猜想」就写猜想，「说不清」是平等选项，兑现率没结论就写「还没有结论」不写 0%。

## 1. 词表：这个 App 里的东西叫什么

| 说 | 不说 | 为什么 |
| --- | --- | --- |
| **深脑** | 服务端、服务器、后端、那边 | 用户面对的是一个产品，不是一套架构 |
| **传 / 送到深脑** | 上传、推送、同步到服务端 | 「送到」是结果，「传」是过程。上传是技术词，推送是推给别人 |
| **导入**（从灵魂卡、从分享） | 拉取、同步（人手动做的时候） | 导入是人做的；同步是卡连上后自己做的 |
| **同步**（灵魂卡连上后自动） | 自动导入 | 用户理解的「同步」正是这件事 |
| **一场会 / 这场** | 会话、session、录音记录 | 「会话」在中文里是聊天 |
| **段** | 分片、chunk | 「第 3 段传到一半断了」人能懂 |
| **记（兑现了 / 取消了）** | 落账、结算、标记 | 落账是我们内部的账本隐喻 |
| **回复** | 应答、回包、响应 | 深脑「回复」看不懂 |
| **存** | 落盘、写入 | 「存不下来，清一下空间」 |
| **灵魂卡** | 录音笔、设备、CB08 | 品牌名。只在「附近设备」列表里提 CB08 这个蓝牙名 |
| **判断 / 承诺 / 预测** | 洞察、insight、atom | 三个词各指一种东西，不混用 |
| **认人** | 说话人识别、标注 | 一个动作一个词 |
| **有原话 / 推断 / 猜想** | 亲证、attested、置信度 | 三档认知等级，用户要一眼分出「这句能不能当真」 |

## 2. 句法

- **一句话一件事。** 超过 25 个字就拆。
- **不用「——」。** 用句号或逗号。破折号在手机上是一条长横，读起来像排版坏了。
- **中圆点一行最多一个。** 「9月5日 14:00 · 52 分钟」可以；「a · b · c · d」不行。
- **引用界面里的东西用「」。** 到「记录」看、点「认人」。引用人说的话也用「」。
- **数字前后留空格，单位紧跟。** 「52 分钟」「10.1 MB」「不到 1 分钟」。零不说零：不到一分钟就说不到一分钟。
- **括号只放技术码。** 「没接下这场（403）」。括号里不再套括号。

## 3. 四种句式

### 按钮：动词，说清点了会发生什么
| 类型 | 例 | 不要 |
| --- | --- | --- |
| 实心（一屏一个） | 开始、下载并安装 v4.3.1、还是分析这条（消耗积分） | 确定、提交 |
| 填充（记一笔） | 兑现了、取消了、应验了、说不清、对、不对 | 是、否 |
| 链接（去别处） | 去那场会、回到原话、看它凭什么这么说、从灵魂卡导入 | 详情、更多 |
| 安静（低频） | 删掉这条、别再看、退出登录、知道了 | 移除、忽略 |
| 对话框 | 确认 = 动词（删掉 / 退出 / 保存 / 继续，同步到当前账号）；不做 = **取消** | 好、算了、确定 |

### 出错：发生了什么 + 为什么 + 怎么办
- 「麦克风被占用了，正在抢回来。已经录到的都在。」
- 「深脑把这场标成了失败，另起一场重传（第 1 次）」
- 「下载的包和清单对不上（校验失败），没有安装。再试一次，或用浏览器下载。」
- 状态码放括号里，人话在括号外。深脑给了 message 就照着显示。

### 空态：这是什么 + 为什么空 + 能做什么
- 「还没有录过。录一场会，它会自己走完转写和分析。」+「录一场」
- 「这场会里没人答应什么。有人说出口「下周给你」这类话时，会出现在这里。」
- 「没取到」和「没有」必须分开说：「没取到，不是没有内容。下拉再试一次。」

### 确认框：标题是动作，正文说后果，按钮是动词
- 「删掉这条录音？」「音频只存在这台手机上，删了找不回来。」「删掉」/「取消」
- 「退出登录？」「还没传完的录音会留在手机上，重新登录后接着传。」「退出」/「取消」

## 4. 语气分档

| 场合 | 语气 | 例 |
| --- | --- | --- |
| 成功 | 陈述，不庆祝 | 「已记：兑现了」「已切到「造物云」」 |
| 进行中 | 说在做什么、要多久 | 「在库里翻资料，这个要久一点」「等第一段传上去后开始（约一分钟）」 |
| 出错 | 平静，给路 | 「没记上：登录失效了」 |
| 警告 | 直说后果 | 「锁屏几分钟后录音可能被系统停掉」 |
| 不确定 | 承认不知道 | 「没测到」「还没有结论」「当初没写清怎么算数，只能凭印象判断」 |

## 5. 4.3.1 改了什么

对 570 条给用户看的字符串过了一遍，改了 60 处：
- 「服务端 / 会话 / 分片 / 落盘 / 应答 / 回包」全部换成词表里的说法（记录页那条「建会话失败（403）」变成「深脑没接下这场（403）」）
- 「推送 / 上传」统一成「传 / 送到深脑」，记录页药丸「上传中」变「在传」
- 21 处「——」拆成两句
- 对话框「算了 / 好」统一成「取消 / 保存」
- 嵌套括号「查不到有没有新版（清单取不到（404））」变「查不到有没有新版：清单取不到，404」
- 今天页两句系统状态：「服务端的迁移还没跑」→「深脑还在升级，这一栏稍后再来」；「取数失败了」→「没取到，不是没有内容。下拉再试一次」

没动的：诊断包里的文字（发给开发者看）、蓝牙底层的步骤名（只进日志）。

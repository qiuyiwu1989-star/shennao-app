## 「完成」的定义

不是「原型里的 32 屏都做完」，是下面这条链在真机上跑通，且每一环都能说清自己在哪一站：

```
拆盒 → 连上灵魂卡 → 录一场（卡或手机）→ 传到深脑 → 出判断 → 落一条承诺 → 第二天被提醒
```

外加三条硬约束：
- **三态齐全**：每一屏的 空 / 离线 / 失败 各自有话说，绝不画成同一屏
- **一屏一个决定**：首屏正文 ≤ 5 条，猜想默认折叠
- **不丢东西**：台账能回答「我的录音卡在哪一站」，且写明它看不到什么

## 推翻此前的三处

1. **「今天」不改成堆叠四段。** 现有三频道左右滑有论证（三种动作分开），拿原型覆盖它是 churn。已按频道模型补齐缺口。
2. **「记录」不新建，在 `HistoryScreen` 上长。** 它已经有四站链。把 BLE 状态条和来源分段加进去即可，不重写。
3. **硬件页第一版不显示额度数字。** 权益依赖「设备 → 权益」这张不存在的表；先显示固定文案「随卡权益：转写不限」，等 Phase 2 接真数。

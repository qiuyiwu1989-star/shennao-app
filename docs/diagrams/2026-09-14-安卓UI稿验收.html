1砍
贯穿全稿的六个系统性问题，比单屏意见更要紧：
  1. 三档认知等级不见了。「有原话 / 推断 / 猜想」是深脑和所有会议纪要产品的分界线，稿里所有判断卡都只写「AI 归纳」。每张判断卡、每条依据都要带这个药丸。
  2. 持续聆听整个缺席。它是主采集方式（昨天一天 6 场都是它录的），首页、记录页空态、首次使用、我的首层都要有它的状态和开关。
  3. 录音中整页变暗。外观是用户的设置项，不能被状态劫持。录音中只亮那一条。
  4. 双入口。首页话筒 + 「记录一段想法」、记录页「+」+ 录音条、来源下拉 + 筛选图标。09-12 定过只留一个录音入口，稿里又长回来了。
  5. 动作套弹层。「处理」→ 弹层 → 「标为完成」是两步做一步的事。动词直接放卡上：兑现了 / 取消了；弹层只留给「不再跟进」这种要二次确认的。
  6. 传输实验室回来了。09-11 邱说不需要，删；诊断走「反馈问题」。

整体评估

能接。信息架构（今天 / 记录 / 问深脑 / 我的）和 4.8 到 4.12 实际演化出来的结构一致，三态（空 / 离线 / 失败）每页都画了，文案克制不替用户下结论，「依据不足」「离线首页」「分析失败原话仍可查看」这几屏比现在 App 做得好，直接采纳。

但它是一套「通用会议助手」的稿，不是深脑的稿。丢掉认知等级、丢掉持续聆听、把「传输实验室」画回来，说明画稿的 Agent 读的是原型不是产品文档。补上上面六条，它就是深脑的。

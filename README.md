# 深脑 App

深脑的手机端。**它不是深脑网页的手机版，是「灵魂卡」这件硬件的兑现面。**

> 硬件卖的是一句承诺——「你说过的话会变成判断」。这句承诺兑现的全过程都发生在
> 这个 App 里：从拆开盒子那一刻，到第一次看见「上周那场会，你答应的三件事有一件逾期了」。

## 不要动的两个包

`app/src/main/java/com/qiuyiwu/shennao/` 下面这两个目录是**真机一条条试出来的**，
重做壳的时候原封搬走，不要重写：

- **`ble/`（13 个文件）** —— CB08 录音笔的 BLE 协议层。厂商文档在删除命令（2-8）上是错的；
  帧头 LEN/CRC 小端而文件列表整数大端；下载请求必须整帧 36B 一次写完；
  裸 OPUS 包要先封成 Ogg；幂等键必须由文件本身决定，还得带上账号。
  这些坑一条都不在文档里，全在代码注释和提交信息里。
- **`record/`（13 个文件）** —— 录音、分片、断点续传、上传管道。
  所有采集入口都汇进这一条 `Ingest`：**新增入口只准新增「源」，不准新增「管道」。**

两个包都是 JVM 可测的。**判据：搬完之后现有单测一条不改照样绿**——改了就说明动了不该动的。

## 同步义务（拆仓之后一定会漂的三处）

这个仓库是从 [`qiuyiwu1989-star/shennao`](https://github.com/qiuyiwu1989-star/shennao)
的 `clients/android` 用 `git subtree split` 抽出来的，历史完整保留。
代价是**下面三样东西的真源在那边**，改了这边不会知道：

| 东西 | 真源 | 漂了会怎样 |
| --- | --- | --- |
| 设计 token（色值、字阶、间距） | `packages/ui/src/tokens.ts` · `docs/DESIGN-SYSTEM.md` | 安卓的颜色会慢慢和网页对不上。**已经发生过**：ink-300 从 `#9096A4` 压到 `#898F9D`，深 7/255，靠人肉眼跟 |
| mobile BFF 的返回形状 | `apps/web/src/app/api/mobile/*` | 加了字段这边不知道，删了字段这边崩 |
| 产品规格 | 那边的 `specs/` 001–009 | 010 引用的上游判据失效了这边看不见 |

**约定**：改动上述任何一处的人，负责在两边各留一条记录。
`docs/design/` 下的摘录文件必须带「摘录于 YYYY-MM-DD」，过期不删——
**过期的日期本身就是警告**。

## 红线

- 不把实时错字、临时说话人推断写成亲证事实。
- 不把 API Key、录音或用户数据写进仓库、日志或文档。`local.properties` 永远不入仓。
- 界面上不出现转写准确率数字，不做模板数量竞赛。
- 不做会中打扰（实时插话、弹窗、副驾驶）。**会中不需要看任何屏幕。**
- 不做隐形偷录。录音状态必须显性化。
- 权益只能加不能减。
